# LeetCode 热题 HOT 100 · ACM 模式完整解题

> 本目录提供 **完整、可直接运行** 的 ACM 式解题代码（标准输入 / 标准输出），
> 与 `hot100/` 的题面模板、`ACM-lc/` 的个人练习互不影响。

## 输入输出约定

- 第 1 行为 `T`，表示测试数据组数，之后紧跟 T 组数据。
- 每组数据的输入格式见各文件头部的「输入格式」说明。
- 每组数据的输出占若干行，组与组之间按顺序依次输出。
- 布尔值统一输出 `true` / `false`；空结果统一输出 `EMPTY`。

## 命名规范

- 分类目录：`NN-题型/`（两位顺序号，固定排序）
- 题目文件：`题号4位补零-中文标题.py`，例如 `0001-两数之和.py`

## 运行方式

```bash
# 用文件头部的样例数据自测
printf '2\n4 9\n2 7 11 15\n3 6\n3 2 4\n' | python3 "acm-solutions/01-哈希/0001-两数之和.py"
```
